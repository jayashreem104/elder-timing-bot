Elder Timing Bot

A small bot trained on question-and-answer pairs about Alexander Elder’s approach to timing trades. It finds the closest pair in its training data and returns that answer. It does not generate new text, so it will say so when a question isn’t covered.

Ask the bot

Training data

One pair per line, written as question ||| answer. Edit or add lines, then train again to see the bot change.

What training does here: it splits each pair into words, drops filler words, weights rarer words more heavily (TF-IDF), and turns every pair into a vector. A new question is turned into a vector the same way, and the pair with the highest cosine similarity wins. Below the match threshold, the bot declines instead of guessing.
